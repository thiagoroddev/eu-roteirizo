## Decisões Tomadas

- **Toque = seleciona E re-aponta** (§6 "comparar destinos é só tocar"); toque no mapa vazio desseleciona; durante o draft o toque vira TOGGLE (§4 p.4).
- **Candidato NUNCA entra sozinho** (§8): só toque no mapa ou "Adicionar" no painel.
- **fitBounds por assinatura** — sem isso cada toggle destruiria o zoom no meio do rascunho (risco nº 1 do plano).
- **Select nativo** para incorporar (sem dependência nova; melhor picker mobile); mais próxima pré-selecionada via `nearestStopTo`.
- **Âncora provisória** = circleMarker slate sem gestos (visual definitivo + arrastar/tornar/resetar = .5); re-projeção automática entregue aqui (1 effect; sem loop — deps não mudam após o RESET).
- Quadrados firmados inertes ao toque (comentado — expansão/edição é a .6); draft sobrevive à troca de modos (vive no reducer, de propósito).
