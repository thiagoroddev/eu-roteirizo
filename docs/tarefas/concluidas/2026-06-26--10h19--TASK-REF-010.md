## Aprendizados Para o Projeto

- **Um pacote de instruções só "carrega sozinho" se houver entry point nativo por ferramenta** — Claude (`CLAUDE.md` + Skills), Codex (`AGENTS.md`), Copilot (`.github/copilot-instructions.md` + `instructions applyTo`). Referência manual é sintoma de entry point ausente.
- **Auto-load por intenção (Skills) vence carregar tudo:** roteadores finos descobertos pela `description` abrem o módulo certo sem inflar o contexto.
- **Conteúdo colado de chat carrega lixo estrutural** (links `claude.ai`, `.md.md`, frontmatter achatado) — vale um passe determinístico de saneamento antes de adotar.
