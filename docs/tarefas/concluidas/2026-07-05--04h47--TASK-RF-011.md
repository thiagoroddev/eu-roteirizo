## Aprendizados Para o Projeto

- **O shell da máquina define `NODE_ENV=production` (e `NODE_TLS_REJECT_UNAUTHORIZED=0`)**: qualquer `npm install` nesse shell **remove as devDependencies** e o Vitest carrega React de produção ("act not supported"). Até a TASK-CHORE-003, rodar testes com `NODE_ENV=test` e installs com `NODE_ENV` limpo.
