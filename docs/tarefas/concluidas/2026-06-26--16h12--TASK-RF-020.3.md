## Decisões Tomadas
- **Cérebro puro + casca fina:** toda a regra (o que desenhar, o que o clique faz, HTML do popup) vive em `markerModels.ts` (testável sem Leaflet); o `RouteMap` só liga ao mapa. Cobertura real sem depender do mock pesado do Leaflet.
- **`fitBounds` separado do render:** em `[stops, rows]`, não em `[models]` — assim expandir/selecionar **não re-enquadra** o mapa. O render usa o zoom já fixado (a ordem dos efeitos garante o `fitBounds` antes do primeiro render).
- **Tooltip no quadrado + popup no círculo:** mantém o resumo rápido (hover) no colapsado e o detalhe (§6) no clique do endereço.
- **Google Maps migrou pro popup:** o clique no quadrado agora **expande**; o link de navegação não se perde (vai no popup do endereço, com a coord do ponto).
- **Parada de 1 endereço:** clicar abre como **círculo selecionado + popup** direto (`nextInteraction` auto-seleciona `i:0`).

## O Que NÃO Foi Feito (e Por Quê)
- **Otimizar o redraw na seleção:** a seleção refaz todos os marcadores (clear+draw) e reabre o popup — pequeno flicker. Aceitável no tamanho de uma rota (~dezenas de paradas); otimização (só `setIcon` do par alterado) fica para depois se incomodar.
- **Rota única / roteirização:** fora de escopo (ADR-008); o reinício `1..N` por parada é do roteirizar (futuro).

## Aprendizados Para o Projeto
- **Separar "o que desenhar/o que o clique faz" (puro) do "como desenhar no Leaflet" (efeito)** torna interações de mapa testáveis sem brigar com o mock do Leaflet — o `markerModels` cobre o comportamento; o componente fica trivial.
- **`fitBounds` tem de morar num efeito keyed só nos dados**, nunca no estado de interação — senão cada clique re-enquadra o mapa. A **ordem dos efeitos** (fit antes do render) entrega o zoom certo no primeiro desenho sem um passo extra.
- **Popup de mapa via `bindPopup(htmlEscapado)`** reusa o `escapeHtml` e evita acoplar a UI a um Dialog do app — conteúdo não-confiável (planilha) entra escapado.
