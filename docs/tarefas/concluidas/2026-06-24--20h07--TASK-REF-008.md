## Decisões Tomadas
- **Primário `#0D82D6`** (não o royal `#0C41D7` nem o ciano): o humano pediu "algo mais claro"; o azure mantém contraste de CTA com texto branco (~3.8:1, AA para texto grande). Ciano vira **acento** (`accent2`), pois reprovaria com texto branco.
- **Duas paletas separadas:** chrome (marca azul, tokens shadcn) × **mapa** (categórica das paradas + semânticas início/livre/badge/âncora). O mapa **não** segue a marca — evita o azul/ciano brigar com o teal das paradas.
- **Tradução M3 → shadcn:** o tema colado era Material (40+ tokens); mapeado para os ~14 tokens shadcn do projeto (HSL).
- **Fonte via Google Fonts (CDN):** offline na 1ª carga cai no fallback. Self-host = melhoria futura (anotado na ADR-006/spec).

## O Que NÃO Foi Feito (e Por Quê)
- **Migrar componentes:** desnecessário — todos consomem tokens (`bg-primary`, `text-foreground`…); só o **valor** mudou, não os nomes de classe.
- **Self-host da fonte:** adiado (não bloqueia; offline cai no fallback de sistema).
- **Dark mode fino:** entregue um conjunto coerente; refino visual fica para quando o dark for usado de fato.

## Aprendizados Para o Projeto
- **Token-first paga:** trocar a marca inteira foi editar `theme.css` — zero mudança em componente. É o dividendo da adoção shadcn (ADR-004).
- **Marca ≠ cores funcionais:** o mapa precisa de uma paleta categórica própria; amarrá-la à marca quebraria a legibilidade. Separar os dois sistemas no design doc evita esse erro.
- **"Algo claro" é ambíguo num CTA:** azul claro ok com texto branco; ciano não — confirmar contraste antes de eleger primário.
