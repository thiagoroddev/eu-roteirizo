## Decisões Tomadas

- **Nome `pre-rota-teste`** — o "teste" no próprio nome impede confundir com produção; a URL de produção futura será outro projeto/decisão.
- **`noindex` desde o primeiro deploy** — o escopo "só pra testes" vira mecânica, não convenção: mesmo que a URL vaze, não indexa.
- **`wrangler` via `npx`, não devDependency** — evita lock-in e a aprovação de dependência para uma ferramenta usada só no deploy manual.
- **Cloudflare Access adiado** — a combinação URL não divulgada + `noindex` + app 100% client-side (dados só no IndexedDB do aparelho) basta para testes; proteção por login é reavaliável se o contexto mudar.
