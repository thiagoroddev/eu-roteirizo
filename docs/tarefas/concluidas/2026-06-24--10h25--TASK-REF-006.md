## Decisões Tomadas
- **Substituir o sistema de tokens custom pelo padrão shadcn (não aditivo):** a pedido explícito ("sem remendos"). Laranja Shopee mapeado para `--primary`; `danger`→`destructive`; `warning` mantido como extensão de token (shadcn não tem). Tokens não usados (`secondary`-azul, `success`, `surface`, `bg`, `text`) removidos — nenhum era referenciado em classe.
- **Modais via Radix `Dialog`** (RouteTable/RouteSimpleTable): cumpre o módulo 13 ("não reinventar modal"); ganha focus-trap/Escape. `showClose={false}` + botão "Fechar" explícito para manter o contrato de UI/testes (texto visível "Fechar").
- **RouteMap fullscreen permanece portal custom:** é uma view imersiva de mapa (Leaflet no container ref), não um card-dialog; só o botão fechar virou `Button`. Convertê-la a Dialog seria invasivo sem ganho claro.
- **Componentes de `ui/` em inglês** (ADR-001); override de eslint `react-refresh/only-export-components` escopado a `ui/` (padrão do ecossistema).
