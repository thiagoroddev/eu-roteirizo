## Planejamento Aprovado

Com a inferência rodando para todo romaneio (RF-016), o tipo de local existe mesmo sem a coluna `Location Type`. Mas os consumidores ainda gateavam na coluna: o Sumário mostrava "Sem dados" na contagem de comerciais e o popup mostrava "Sem dados" no tipo de local (rota única). Exibir ambos por inferência, sem gatear na coluna.

## Execução
- **Contagem (Sumário):** `countCommercialAddresses` deixou de receber/gatear em `availableCols.includes(LOCATION_TYPE)` — agora conta sempre por `resolveLocationType` (inferência para todos). `useRouteSummary` atualizado para `countCommercialAddresses(rows)`.
- **Popup (mapa):** a causa do "Sem dados" era `getCommercialDisplayStatus(row)`: o type guard `isRowData` exige a chave `Location Type` no objeto, ausente na rota única → caía no ramo string → "Sem dados". Trocado para `getCommercialDisplayStatus(finalType)` (o `finalType = resolveLocationType(row)` já era computado para o ícone), que entra pelo ramo string com a chave já resolvida — funciona nos dois modos.

## Decisões Tomadas
- **Passar `finalType` (string) ao popup, não "consertar" `isRowData`:** alargar o type guard mudaria o comportamento de todos os callers; passar o type já resolvido é local, mínimo e segue o padrão que a `RouteSimpleTable` já usava (`getCommercialDisplayStatus(resolvedType)`).
- **Contagem sempre por inferência:** alinhado ao RF-016 ("inferência para todos"). Multi-rota inalterado na prática (sempre tem a coluna; e o `resolveLocationType` já inferia por cima dela).
- **Label do popup mantido "Horário comercial?":** é o rótulo pré-existente (igual ao da tabela simplificada) e o dado por trás é o tipo de local. Relabel para "Tipo de local" seria decisão de copy — fica como follow-up se o humano quiser.

## O Que NÃO Foi Feito (e Por Quê)
- **Refatorar `isRowData`:** nenhum caller passa mais um row cru de rota única para `getCommercialDisplayStatus` (RouteMap usa `finalType`, RouteSimpleTable usa string), então a "armadilha" não é atingida na prática. Alargar o guard fica anotado como melhoria latente.
