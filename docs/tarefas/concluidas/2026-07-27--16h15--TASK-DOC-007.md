## Decisões Tomadas

- **Capturar telas reais em vez de usar os mockups:** os mockups mostram funcionalidade inexistente. Num README cujo propósito declarado é ser honesto sobre o estágio, isso se anularia.
- **Romaneio fictício com coordenadas reais:** endereços e pacotes são inventados, mas as coordenadas precisam existir na malha do OSM, senão o grafo não carrega e a captura mostraria estado de erro. Logradouros públicos de Copacabana/Ipanema, nenhum dado pessoal.
- **Declarar o teste vermelho no próprio README:** contraintuitivo para peça de portfólio, mas um defeito rastreado com ID demonstra processo; escondê-lo e ser descoberto custa mais. Declarado em nota, não na chamada principal.
- **`version` 0.0.0 → 0.1.0:** `0.0.0` é default de scaffold e comunica "nada aqui". `0.1.0` comunica protótipo com um marco.
- **`license: "UNLICENSED"` no `package.json`, sem arquivo LICENSE:** é o valor canônico do npm para código não licenciado; sem arquivo, o padrão legal já é todos os direitos reservados.
- **Não usar os mockups em lugar nenhum:** ficam em `prototipos/` como o que são — artefato de design.

## O Que NÃO Foi Feito (e Por Quê)

- **Renomear o repositório no GitHub:** é ação na conta do humano, feita pela web. Os links do README e o `repository` do `package.json` já apontam para `eu-roteirizo`; ficam **quebrados até o rename ser feito**.
- **Atualizar o remote do git local:** depende do rename acima.

- **Traduzir para inglês:** decisão do humano por português.

## Aprendizados Para o Projeto

- **README de portfólio e README de mantenedor são documentos diferentes e o repositório precisava dos dois.** O que existia servia ao mantenedor, estava na pasta errada para o visitante, e carregava boilerplate de scaffold que ninguém tinha lido desde o primeiro commit.
- **Automatizar o clique na própria interface é um teste de coerência barato.** Em três tentativas o roteiro expôs que o rótulo do Sumário divergiu da constante que deveria defini-lo (REF-017) — coisa que a suíte verde não pega, porque nenhum teste afirma o texto daquele botão.
- **Honestidade tem retorno prático num README de portfólio.** Declarar o teste vermelho com o ID da tarefa e listar o que o app não faz custa menos que ser pego, e a seção que mais demonstra engenharia acabou sendo a que admite uma falha do Overpass e mostra o retry funcionando.
- **Mockup no README é armadilha silenciosa.** Os PNGs já traziam o nome novo e pareciam prontos para uso; só a leitura atenta revelou que exibiam uma tela ("Iniciar rota", "LIVE TRACKING") que a RF-009 ainda não implementou.
