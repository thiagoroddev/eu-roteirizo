## Decisões Tomadas
- **Structured clone > serialização manual:** o IndexedDB clona `Map`/`Set` nativamente (e o `fake-indexeddb` idem). Guardar o grafo direto é mais simples e foi validado por teste (`coords.get(1)` volta correto após o round-trip). Se algum runtime não suportar, troco por arrays — mas é padrão.
- **Orquestrador `loadRoadGraph` no serviço (services→utils):** entrega o aceite "2ª abertura não bate no Overpass" num único ponto reusável pela RF-006; o acoplamento services→osm é na direção certa (camada alta → baixa).
- **Invalidação por versão do DB, não por campo no registro:** a via idiomática do IndexedDB (bump + `upgrade`) cobre mudança de formato sem um campo `version` por registro; o TTL cobre frescor. Mais simples.
- **TTL testável por parâmetro (`ttlMs:0`)** em vez de fake timers — determinístico e sem interação chata com o IndexedDB falso.

## Aprendizados Para o Projeto
- **IndexedDB clona `Map` de graça:** o *structured clone* preserva `Map`/`Set`, então estruturas de domínio com `Map` persistem sem serialização manual (validar com `fake-indexeddb`, que segue o mesmo algoritmo).
