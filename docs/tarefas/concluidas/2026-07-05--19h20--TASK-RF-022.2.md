## Decisões Tomadas

- **`<details>/<summary>` nativo, não Radix Collapsible:** é o primitivo exato de spoiler, acessível por padrão e zero dependência — não conta como "reinventar primitivo complexo" (ADR-004 mira modal/dropdown/combobox).
- **Persistência dentro do `useRouteUploader`:** o hook já é o dono do fluxo de upload; a UI só exibe o resultado. Falha de save nunca bloqueia a visualização (registrado no JSDoc do tipo).
- **Aviso de duplicado usa o `fileName` do registro existente** ("já importado como X") — a seleção automática na aba Rotas fica para a .3, como planejado.
