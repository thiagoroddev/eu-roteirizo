## Decisões Tomadas

- **Toque armado + confirmação no ponto** (decisões do humano 08/07) — sem definição acidental; "partir deste endereço" explícito.
- **Estado efêmero da UI fora do reducer** (useState no MapScreen); "Redefinir início" mantém o início atual até o novo ser definido.
- **Re-apontar no mesmo alvo = no-op** (des-apontar criaria um estado "sem sugestão" que a spec não tem).
- **fitBounds inclui o início, não a sugestão** — re-apontar não re-enquadra o mapa.
- **Re-projeção automática quando o grafo chega** por derivação pura (memos recalculam a prop do overlay) — zero código extra.
- GPS fora do Rio (`isWithinRioBounds`) → aviso, não define (RN-01 aplicada ao início; spec era omissa).
