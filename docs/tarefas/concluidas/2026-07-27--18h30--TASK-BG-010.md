**O gate `npx tsc --noEmit`, documentado no núcleo e rotulado APROVADO em todo registro de tarefa deste projeto, nunca checou coisa alguma.**

- **Evidência:** `npx tsc --noEmit --listFiles | wc -l` → **0**. E o comando saiu verde enquanto havia erro de sintaxe JSX no código — quem pegou foi o ESLint.
- **Causa:** o `tsconfig.json` da raiz é *solution-style* (`"files": []` + só `references`). O `tsc` **não segue project references** sem `-b`; sem arquivos a checar, ele sai 0.

## Aprendizados Para o Projeto

- **`w-screen` dentro de container com padding é sempre estouro.** 100vw ignora o pai; em layout mobile-first isso arrasta a página inteira. Se o objetivo é "ocupar a largura disponível", é `w-full`.
- **`overflow-auto` não funciona se um ancestral for flex item sem `min-w-0`.** Flex item nasce com `min-width: auto` e se recusa a encolher abaixo do conteúdo mínimo — o container de rolagem nunca chega a ter o que rolar. Os dois andam juntos.
- **Depois de duas tentativas erradas, medir sai mais barato que a terceira tentativa.** O script que varre o DOM atrás de quem passa da borda apontou o culpado de primeira, depois de dois chutes.
- **Verificação automatizada precisa provar que o alvo existe antes de medi-lo.** Um erro de compilação fez o Vite renderizar um overlay que cabe na viewport, e a métrica de "não estoura" passou numa página que nem carregou. Toda medição de UI precisa de uma asserção-guarda de que o app renderizou.
- **Gate verde não é gate executado.** O `tsc --noEmit` saía 0 há meses sem ler um arquivo sequer. Vale checar periodicamente se cada gate ainda tem dentes — `--listFiles` responde em um segundo.
