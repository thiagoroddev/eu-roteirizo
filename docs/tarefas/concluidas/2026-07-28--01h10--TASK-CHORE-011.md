## Decisões Tomadas

- **Não reescrever o README.** A conferência mostrou que ele já era honesto e preciso. Reescrever
  texto correto para parecer trabalho seria ruído. As adições foram só onde havia lacuna real:
  caminho curto para quem avalia, e prova em vez de afirmação na seção de IA.
- **Três paradas ligadas por um traçado, não um pino de mapa.** Pino é o ícone genérico de qualquer
  app de mapa e vira mancha a 32px. Três pontos numa diagonal dizem "paradas em sequência", que é o
  que este app faz, e sobrevivem à redução.
- **Card de Open Graph gerado, não captura reaproveitada.** Divergiu do plano e está registrado
  acima com o motivo.
- **`X-Robots-Tag: noindex` mantido, justificativa reescrita.** O comentário do arquivo afirmava "a
  URL não é divulgada", o que deixou de ser verdade no instante em que o README a publicou. A regra
  continua certa, a razão é outra: protótipo em construção não deve ser achado por quem procura
  produto pronto.
- **`LICENSE` proprietária, sabendo que o GitHub não vai exibir badge.** É o resultado desejado:
  código visível para avaliação, sem virar software livre por omissão. Inclui a nota de que a malha
  viária vem do OpenStreetMap sob ODbL.
- **Tagline ajustada.** Dizia "rotas otimizadas", e otimização automática é justamente o que **não**
  existe (RF-012, pendente). Num README de portfólio isso seria alegação falsa. Trocada por
  "paradas de veículo com circuitos de entrega a pé", que é o que o código faz hoje.

## Aprendizados Para o Projeto

- **"Deixar apresentável" quase nunca é sobre o texto.** O README já estava bom; o que denunciava
  projeto inacabado era o favicon do Vite, o manifest com as cores erradas e a ausência de licença.
  A primeira coisa que um avaliador vê é a aba do navegador, não o parágrafo de abertura.
- **Arquivo em `public/` com nome que uma ferramenta também emite é colisão silenciosa.** O
  `public/sw.js` foi copiado e sobrescrito pelo Workbox a cada build, sem erro, sem aviso. Vale
  conferir o `dist/` quando `public/` e um plugin disputam o mesmo nome.
- **Documentação de infraestrutura envelhece calada.** A URL do deploy mudou no `package.json` e
  dois documentos continuaram apontando para a antiga. Ao mexer num script de deploy, grepar a URL
  antiga na documentação deveria ser parte do fecho.
- **Afirmação de capacidade em README de portfólio é alegação sobre você.** "Rotas otimizadas"
  descrevia uma funcionalidade pendente. Num currículo, o custo de exagerar não é estilístico.
